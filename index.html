Leaflet Relief Plugin Demo

This demo showcases the Leaflet Relief plugin with both hillshade and slope visualization modes. The plugin uses Mapterhorn elevation tiles (512×512 WebP) to create terrain visualizations. View on GitHub →

  • Hillshade Mode: Simulates sunlight on terrain to show relief
  • Slope Mode: Colors terrain by steepness (green = flat, red = steep)
  • Archeo Mode: Multi-directional hillshade with warm/cool tinting of convex/concave micro-relief
  • Tricolor Mode: Three hillshades from different azimuths mapped to the red, green and blue channels
  • Interactive Controls: Every rendering parameter of the active mode is adjustable in real-time, along with the elevation source and its parent-tile fallback depth
  • Hillshade Colors: Choose from grayscale, sepia, blue-tinted, green-tinted, or warm color schemes
  • Slope Colors: Choose from default, glacial, thermal, or earth color schemes for slope visualization
